# Aula de Git: Receitas em Markdown

Este repositório foi utilizado em uma aula prática de Git. O exercício tem como objetivo apresentar o uso de repositórios, branches, commits e colaboração no desenvolvimento de arquivos de documentação.

O conteúdo previsto para a atividade é a criação e a organização de receitas usando a linguagem de marcação Markdown.

## Conteúdo

- Conceitos básicos de Git e GitHub
- Criação e navegação entre branches
- Registro de alterações com commits
- Colaboração por meio de arquivos Markdown
- Criação de receitas com títulos, listas, links e outros recursos de formatação

## Estrutura do repositório

- [`docs/`](./docs/): materiais e documentação da atividade
- [`docs/receitas/`](./docs/receitas/): receitas criadas em Markdown

Cada arquivo da pasta de receitas representa uma receita que pode ser criada, alterada e revisada durante a aula, permitindo praticar o fluxo de trabalho do Git em um exemplo simples e colaborativo.
