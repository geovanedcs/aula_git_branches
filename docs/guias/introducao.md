# Guia de Introdução

Este guia apresenta o fluxo básico da atividade de Git com receitas em Markdown.

## Objetivo

Criar ou atualizar uma receita, registrar as alterações com Git e colaborar com o repositório por meio de branches e commits.

## Fluxo sugerido

1. Atualize sua cópia local do repositório.
2. Crie uma branch para a sua receita ou alteração.
3. Adicione ou edite um arquivo dentro de `docs/receitas/`.
4. Confira as alterações e registre um commit com uma mensagem clara.
5. Envie a branch para o repositório remoto.
6. Abra um pull request para revisar e integrar a alteração.

## Estrutura esperada da receita

Uma receita deve conter um título, uma lista de ingredientes e o modo de preparo. Recursos de formatação podem ser consultados na [Referência de Markdown](../referencias/markdown.md).

## Exemplo de nome de branch

```text
receita-bolo-de-chocolate
```

Use nomes curtos e descritivos para facilitar a identificação do trabalho.
