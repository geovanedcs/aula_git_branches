# Referência de Markdown

Markdown é uma linguagem simples para formatar arquivos de texto. As receitas deste repositório usam essa sintaxe.

## Títulos

```markdown
# Título da receita

## Ingredientes

### Observações
```

## Listas

Use `-` para criar uma lista:

```markdown
- 2 xícaras de farinha
- 1 colher de açúcar
```

Para uma lista numerada, use números:

```markdown
1. Misture os ingredientes.
2. Leve ao forno.
3. Sirva.
```

## Destaques e links

```markdown
**texto em negrito**
_texto em itálico_
[Nome do link](https://exemplo.com)
```

## Modelo de receita

```markdown
# Nome da receita

## Ingredientes

- Ingrediente 1
- Ingrediente 2

## Modo de preparo

1. Primeiro passo.
2. Segundo passo.
3. Terceiro passo.
```
